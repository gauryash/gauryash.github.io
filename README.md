# Yash Gaur

This is my personal site and notes reader.

Edit these files:

- `index.html` for text and links
- `styles.css` for design and reader layout
- `script.js` for routing, the theme button, notes, and keys 1–4

Published routes:

- `/` and `/home` — introduction
- `/work` — experience and skills
- `/wiki` — notes index
- `/wiki/<post-slug>` — an individual note
- `/reading` — reading list

Open `index.html` to view the site.

Push to `main` to publish it on GitHub Pages.

Design elements inspired by [Freaktion ↗](https://www.freaktion.xyz/).
